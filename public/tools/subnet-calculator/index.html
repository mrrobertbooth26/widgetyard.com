Understanding CIDR

The prefix tells you how many leading bits describe the network. For example, /24 corresponds to 255.255.255.0 and contains 256 total addresses.

Special cases

Modern point-to-point /31 networks can use both addresses. A /32 identifies a single host, so this calculator reports one usable address for it.
